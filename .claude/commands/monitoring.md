# /monitoring — 관측 상태 확인

먼저 `.claude/rules/workflow.md`, 관련 인프라 이슈와 배포 설정을 읽는다. 과거 Railway/Grafana 문서는 참고이며 현 운영 상태의 증거는 아니다.

1. 요청된 환경·엔드포인트·메트릭 대상을 확인한다. 대상이 불명확하면 오래된 주소로 운영 상태를 추정하지 않는다.
2. 헬스·로그·메트릭은 범위를 제한한 읽기 전용 명령으로 조회한다.
3. 관측 시각·정상/오류 결과·확인 못 한 범위를 구분한다. 민감한 로그·키·개인 정보를 이슈에 복사하지 않는다.
4. 원인과 다음 행동을 이슈에 남긴다. 관측 요청만으로 재시작·배포·DB 변경을 수행하지 않는다.

`/deploy`와 같은 실제 대상 확인 절차를 재사용하며 모니터링 지침을 두 벌 유지하지 않는다.
