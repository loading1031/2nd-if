## 목표 미학

한 줄로: **"중세 필사본 × 모던 북 디자인"**. 양피지 톤의 크림색 배경 위에, 한 가지 잉크 톤으로 그린 캐릭터/오브젝트가 텍스트 사이를 가르며 놓이는 그림책. 디즈니 카툰 아님. 포스터 컬러 일러스트 아님.

## 핵심 레퍼런스 Top 5 (분석)

### 1. `01-pretext-riyvir-dragon.jpg` ← 사용자가 공유한 비디오의 원본
**이 한 장이 제품의 목표 스크린이다.**
- 배경: 크림 양피지 (#f4eee0 근방)
- 드래곤: **순수 검정 실루엣**. 그라디언트 없음. 라인아트도 아니고 완전 채운 실루엣.
- 포즈: 왼쪽 상단에서 목과 날개를 위로 펼친 뒤, 몸통이 아래로 구부러져 내려오며 **텍스트 컬럼의 왼쪽 경계를 만든다**.
- 타이포: 블랙레터 혹은 올드 스타일 세리프. 드롭캡은 장식 이니셜(검은 사각형 안에 흰 문자 + 덩굴 장식).
- 본문 색: 다크 워밍 브라운 (#2a1a0a 근방, 순수 #000 아님)
- 저작: "Click for fire! By Birdabo"

**왜 이게 목표냐:** 드래곤이 "삽화"가 아니라 "페이지의 물리적 객체"로 기능한다. Pretext의 장애물 회피가 드래곤의 실제 실루엣을 따라 텍스트 라인 폭을 결정하기 때문에, 읽는 행위 자체가 드래곤을 둘러싸고 일어난다.

### 2. `43-medieval-harley-dragon.jpg` — Harley MS 3244 (13세기 베스티어리)
**800년 전에 이미 Pretext를 했다.**
- 붉은색 + 녹색 디테일의 드래곤이 **두 단 고딕 스크립트를 대각선으로 가른다**.
- 드래곤 꼬리가 본문의 첫 단 끝까지 늘어지며 자연스럽게 페이지 레이아웃을 분할.
- 장르별 스킨 팩의 "fantasy-medieval" 팩의 레퍼런스 픽셀 밀도/선 두께 기준점.

### 3. `30-beardsley-merlin.jpg` — Beardsley, 1893
**가장 엄격한 흑백 버전.**
- 순수 검정/흰색 2톤. 회색 없음.
- 굵은 외곽선 + 면 대비로만 형상 성립. 중간톤 패턴(dot/stripe)으로만 텍스처 표현.
- 모바일/저대역폭에서도 완벽하게 렌더링될 "최소 충실도 팩"의 기준.

### 4. `20-rackham-dragon-dublin.jpg` — Arthur Rackham
**파스텔+라인 — Dulac보다 담백한 파생 옵션.**
- 흑색 라인아트 위에 수채(세피아/퍼플/블루)를 **투명하게** 얹는 방식.
- 배경이 희끗한 양피지여서 이중톤 레이어링과 잘 붙음.
- "romance" / "daily" 장르 스킨 팩 후보 톤.

### 5. `41-medieval-stgeorge-dragon.jpg` — Saint George (Book of Hours)
**화려한 컬러 풀버전 — 유료 팩 상한 기준.**
- 금박 + 울트라마린 + 버밀리온 + 아이보리. 여백 전체가 덩굴 장식으로 채워짐.
- 이 정도 밀도는 무료 팩에서는 금지. 유료/시그니처 팩용.

## 2차 레퍼런스

- `21, 22` (Rackham 드래곤): 드래곤 포즈 바리에이션. 특히 22는 skeleton + dragon 구성으로 공포 장르 스킨 후보.
- `42, 44, 45` (중세 필사본 다양): 덩굴/곁장식(marginalia) 패턴 소스.
- `50, 51` (Dulac): 밤하늘 + 달 톤. "mystery" 스킨 후보.
- `70–72` (Beowulf/Siegfried): 현대 서사시 삽화 → 쇼펜하우어 시대 인쇄 판타지의 페이지 레이아웃 참고.
- `02–13` (Pretext 기타): 물리 효과/리퀴드/쓰리디 → 2차 확장용 "다음 시즌" 효과 참고.
