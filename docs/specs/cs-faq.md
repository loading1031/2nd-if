# CS FAQ 페이지

> 기획 문서

## 상태: 기획 완료

## 개요

자주 묻는 질문(FAQ) 페이지. 카테고리별로 질문을 분류하고 검색 기능을 제공하여 사용자가 스스로 문제를 해결할 수 있게 한다. 해결되지 않으면 1:1 CS 채팅으로 연결한다.

## 요구사항

### 핵심
- FAQ 항목은 DB가 아닌 템플릿에 하드코딩 (초기 MVP, 추후 DB 이관 가능)
- 카테고리: 서비스 소개, 계정, 읽기, 창작, 라이선스, 결제/수익, 기술/오류
- DaisyUI collapse 컴포넌트로 아코디언 UI
- 검색: 클라이언트 JS keyup으로 키워드 필터링 (서버 요청 없음)
- 카테고리 탭 클릭 시 해당 카테고리만 표시
- 하단에 "해결되지 않았나요?" → 1:1 채팅 링크 (`/cs/`)
- 비로그인 사용자도 FAQ 열람 가능 (채팅은 로그인 필요)
- URL: `/cs/faq/`

### 확장성
- 향후: FAQ 항목 DB 이관 (관리자 CRUD)
- 향후: FAQ 자동응답 봇 연동 (LLM 기반)

## 사용자 플로우

### 정상 - FAQ 열람
1. 사용자 (로그인/비로그인) → `/cs/faq/` 접속
2. 카테고리별 질문 목록 표시 (기본: 전체)
3. 질문 클릭 → 아코디언 열려 답변 표시
4. 다른 질문 클릭 → 이전 답변 닫히고 새 답변 열림

### 정상 - 카테고리 필터
1. 카테고리 탭 클릭 (예: "계정")
2. 해당 카테고리 질문만 표시
3. "전체" 탭 클릭 → 모든 카테고리 질문 표시

### 정상 - 검색
1. 검색 입력란에 키워드 입력 (예: "비밀번호")
2. 키워드가 포함된 질문만 실시간 필터링 표시
3. 검색어 삭제 → 전체 질문 다시 표시

### 정상 - 1:1 채팅 연결
1. FAQ 하단 "1:1 채팅으로 문의하기" 클릭
2. `/cs/`로 이동 (로그인 필요)

### 에러 - 미로그인 상태에서 채팅 시도
1. 비로그인 사용자 → "1:1 채팅으로 문의하기" 클릭
2. `/cs/` → 로그인 페이지 리다이렉트 (기존 cs-chat 로직)

### 엣지 - 검색 결과 없음
1. 검색어 입력 → 매칭 질문 없음
2. "검색 결과가 없습니다. 1:1 채팅으로 문의해주세요." 안내 표시
