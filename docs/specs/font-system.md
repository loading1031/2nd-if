# 장르별 글씨체 시스템

> 기획 문서

## 상태: 기획 완료

## 개요
원작자가 작품 생성 시 글씨체를 선택하여 장르 분위기에 맞는 읽기 경험을 제공한다.

## 글씨체 옵션

| 코드 | 이름 | 폰트 | 적합 장르 | 라이선스 |
|------|------|------|----------|---------|
| default | 기본 | Pretendard | 현대/일반 | SIL OFL |
| serif | 명조 | Noto Serif KR | 판타지/로맨스 | SIL OFL |
| classic | 궁서 | Gowun Batang | 무협/사극 | SIL OFL |
| modern | 고딕 | Noto Sans KR | SF/현대물 | SIL OFL |

모든 폰트는 Google Fonts에서 무료 제공 (상업적 사용 가능).

## Work 모델 확장

| 필드 | 타입 | 기본값 | 비고 |
|------|------|--------|------|
| font | CharField(20) | "default" | 글씨체 선택 |

## 적용 범위
- 에피소드 읽기 페이지의 본문에만 적용
- 작품 목록, 카드 등 UI는 기본 폰트 유지
- 원작자가 작품 생성/수정 시 선택

## 사용자 플로우

### 정상
1. 원작자: 작품 생성 → 글씨체 선택 (4종 중 택1)
2. 독자: 에피소드 읽기 → 선택된 글씨체로 본문 표시
3. 원작자: 작품 수정 → 글씨체 변경 가능
