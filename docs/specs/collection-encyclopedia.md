# 작품별 수집 도감

## 결론

2026-10-17 사용자 결정으로 Blender 장면·루프 영상·GLB/three.js 화면 반응 기획을 폐기하고 작품별 수집 도감으로 전환한다. 이전 PoC는 참고 이력이며 출시 요구사항이 아니다. 기존 텍스트 독서·페이지 가독성 개선은 별도 판단한다.

## 확정된 요구사항

- 작품마다 도감을 제공하여 사물·동물·몬스터 등을 수집하고 확인하는 재미를 제공한다.
- 작품 장르(무협/판타지/로맨스) 아래 1차 분류와 2차 세부 대상을 둔다. 형태가 없는 추상 개념은 초기 에셋 대상에서 보류한다.
- Game-icons SVG를 우선 활용하고 부족한 대상은 직접 제작 SVG로 보완한다. 하나의 에셋에는 대상 하나가 분명하게 보여야 한다.
- 에셋 식별자와 작품의 단어·동의어·문맥을 연결한다. 같은 이름의 서로 다른 대상은 작가가 선택하고, 미확정 충돌을 임의로 해소하지 않는다.
- 에셋 모양과 색상 정보를 분리한다. 같은 brute SVG도 작품의 파란 brute 등 묘사에 따라 팔레트 색을 입힌다. 작품별 선택이 다른 작품의 에셋이나 배색을 바꾸지 않는다.
- 공식 팔레트 8종의 배경색과 전경색을 사용한다. 입력 HEX/등록된 색 이름에서 가까운 팔레트 색을 제안하고 작가가 확인한다. 색상 미지정·해석 실패 시 흑백 기본형을 유지한다.
- 저작자·출처·라이선스와 배색 수정 표시를 유지한다. 기존 무료/유료 설정집의 권한·버전 정책 자체를 이 전환으로 폐기하지 않는다.

## 제안하는 흐름과 미정 사항

작가: 대상 후보 선택 → 작품 표현과 에셋 연결 → 색상 확인 → 독자에게 공개할 범위 승인.
독자: 작품 도감 진입 → 분류별 수집 현황 → 획득 대상 상세 → 등장한 회차로 이동.
위 흐름의 화면 구성과 다음 결정은 후속 기획에서 확정한다.

- 수집 트리거: 독서 진도 도달, 표현 탭, 수동 수집 중 어떤 방식을 쓸지
- 미획득 대상의 이름·실루엣·총 개수를 어디까지 숨길지와 회차별 스포일러 제한
- 로그인 전후 수집 기록, 재독·중복 등장·원작/분기별 수집 범위
- 작가의 본문 수정·에셋/색상 매핑 갱신 후 기존 수집 기록 처리
- 도감 비활성화/접근성, 빈 목록·미매핑·삭제된 회차 등의 상태

## 완료 기준과 실행 순서

1. #33 에셋·분류·단어·색상 매핑 기반을 정리한다. 현재 로컬 갤러리와 유사색 함수는 준비되어 있으나 제품 연동 완료는 아니다.
2. #15에서 수집/공개/스포일러 결정을 정하고 도감 화면 디자인 및 구현 작업을 실행 가능한 단위로 연결한다. 그 전에는 기획 완료 처리하지 않는다.
3. #32의 작가 에셋 매핑 구현과 연계하여 작품별 대상·팔레트 정보를 저장한다.
4. 후속 도감 디자인·개발에서 실제 수집과 열람 흐름을 구현한다. 독서 진도보다 뒤의 정보가 노출되지 않고 작품 간 수집·색상이 섞이지 않는지 확인한다.
