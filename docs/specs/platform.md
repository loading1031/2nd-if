# 2nd-if 플랫폼 개요

> 기획 문서

## 상태: 기획 완료

## 비전
독자들이 원작 소설에서 스토리를 직접 분기하고, 밈처럼 콘텐츠를 재생산하는 2차 창작 플랫폼.
연재 중단된 작품의 스토리를 이어갈 수 있는 가능성도 제공한다.

## 핵심 컨셉
- **Git for Novels** — 소설에 branch/merge 개념 적용
- 원작에서 분기하여 새로운 스토리라인 생성
- 인기 분기를 가중치로 측정하고 추천

## 사용자 역할
모든 가입자는 동일한 권한. 자신이 생성한 콘텐츠 여부로 역할이 결정됨.
- **원작자**: 작품을 처음 생성한 사람
- **2차 창작자**: 분기를 만든 사람
- **독자**: 읽기만 하는 사람

## 기술 스택
- **백엔드**: Django 6.0+ (Native Async ORM)
- **프론트엔드**: HTMX + DaisyUI + Tailwind CSS v4
- **에디터**: TipTap vanilla JS (에피소드 작성)
- **스토리 그래프**: Neo4j + neomodel (분기/가중치/경로)
- **일반 데이터**: Django ORM (PostgreSQL/SQLite) — 유저, 인증, 라이선스 등

## MVP 범위

### 포함
- [[auth]] — 회원가입/로그인/로그아웃
- [[story]] — 원작 등록/연재 (TipTap)
- [[branch]] — 분기 생성 (20화 이전 제한)
- [[next-episode-ui]] — 다음 화 선택 UI (가중치 정렬)
- [[license]] — 라이선스 설정

### 제외 (후속)
- [[merge]] — 분기 합치기
- [[plagiarism]] — 표절 검사/유사도 감지
- [[revenue]] — 수익 모델 (유료 작품, 포인트)
- [[dashboard]] — 인기도 대시보드
- [[moderation]] — 신고/모더레이션
- 소셜 로그인, 이메일 인증
- 웹툰/시나리오 등 확장
