# 2nd-if 플랫폼 개요

> 기획 문서

## 상태: 재기획 (제품 방향 갱신)

## 비전
자유롭게 공개되는 소설에서 독자의 실제 읽기 흐름을 작가 인사이트로 돌려주고, 작품 분기와 재사용 가능한 설정집으로 창작을 돕는 플랫폼.
주요 차별점은 읽기 지표를 작품의 품질 점수로 단정하지 않고, 독자가 어디까지 읽고 어떤 경로를 택했는지 작가가 살필 수 있게 하는 것이다.

## 핵심 컨셉
- 작품은 공개/링크 공개/비공개로 공유하고, 열람 정책·재사용 권한·지표 공개 권한을 서로 분리한다.
- 작가는 타임라인에 등록된 지점에서만 2차 창작 분기를 허용할 수 있다.
- 설정집 제작자는 정적 설정과 Blender 시각 에셋을 무료 또는 유료로 배포하며, 작품은 설정집의 필요한 항목을 채택한다.
- 독서 행동과 내부 유입은 GA4로 수집해 BigQuery까지 내보낸다. 작가는 자기 작품 지표와 공용 컴포넌트 전체 집계만, 선택한 공개 범위에 맞춰 본다.

## 사용자 역할
모든 가입자는 동일한 권한. 자신이 생성한 콘텐츠 여부로 역할이 결정됨.
- **원작자**: 작품을 처음 생성한 사람
- **2차 창작자**: 분기를 만든 사람
- **독자**: 읽기만 하는 사람

## 기술 스택
- **백엔드**: Django 6.0+ (Native Async ORM)
- **프론트엔드**: HTMX + DaisyUI + Tailwind CSS v4
- **에디터**: TipTap vanilla JS (에피소드 작성)
- **스토리 그래프**: 저장 기술 미확정. 분기·경로의 데이터 모델은 현재 구현 코드와 PostgreSQL 통합 상태를 확인한 뒤 결정한다.
- **일반 데이터**: Django ORM (PostgreSQL/SQLite) — 유저, 인증, 라이선스 등
