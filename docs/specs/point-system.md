# 포인트 시스템

> 기획 문서

## 상태: 기획 중 (MVP 이후)

## 개요
포인트는 원작자가 2차 창작자에게 지급하는 **홍보 보상**이다.
원작자의 작품 통계(조회수, 좋아요, 클릭수)에서 포인트가 생성되고, 이를 기여한 2차 창작자에게 분배한다.

## 포인트의 본질

```
작품(Work)마다 고유한 포인트 풀 보유
    ↓
원작의 인기 통계 → 포인트 풀 생성 (작품별 홍보 예산)
    ↓
2차 창작자의 홍보 기여도에 따라 분배
    ↓
2차 창작자는 포인트로 유료 에피소드 열람
    ↓
열람 시 해당 작품의 포인트 풀에서 차감
```

- 포인트는 **작품(Work) 단위의 홍보 예산**
- 원작자가 독자와 함께 홍보할 수 있는 수단
- 원작자 입장: 포인트 풀 = 홍보비 예산. 2차 창작자가 홍보해주니 그 대가로 콘텐츠 열람 허용
- 포인트로 열람된 건 = 원작자의 포인트 풀에서 차감 (코인 수익 대신 홍보 효과를 선택한 것)
- 플랫폼은 포인트 시스템만 제공, 돈을 만지지 않음

## 포인트 생성 (작품별 풀)

**각 작품(Work)마다** 통계를 기반으로 매월 포인트 풀이 생성된다.

### 통계 기반 산출
| 지표 | 설명 |
|------|------|
| 조회수 | 해당 작품 에피소드 총 조회수 |
| 좋아요 수 | 해당 작품 에피소드 총 좋아요 |
| 클릭수 | 다음 화 선택에서 원작 경로 클릭 |

- 포인트 풀 = 작품별 통계 기반 공식 (추후 확정)
- 인기 작품일수록 더 많은 포인트 풀 생성
- **작품별로 한정된 풀** → 희소성 유지, 작품마다 독립 운영

## 포인트 분배 (2차 창작자)

한정된 포인트 풀을 2차 창작자들에게 기여도 기반 분배.

### 기여도 측정
| 지표 | 설명 |
|------|------|
| 분기 → 원작 유입 | 분기를 읽고 원작으로 이동한 독자 수 |
| 분기 engagement | 분기 자체의 조회수, 좋아요 |
| 분기 확산 | 해당 분기에서 또 분기가 생긴 수 |

- 기여도 높은 2차 창작자가 더 많은 포인트 획득
- 잘 되는 2차 창작자 = 원작 홍보를 잘 해주는 사람

## 포인트 사용

- 유료 에피소드 열람 (코인 대신)
- 플랫폼 내에서만 순환, **현금화 불가**

## 2차 창작자의 성장 경로

```
신인 2차 창작자
    ↓ 포인트로 유료 작품 읽으며 실력 향상
    ↓ 분기 인기 → 더 많은 포인트 획득
    ↓ 팬층 확보
    ↓
인기 2차 창작자
    ↓ 자신의 분기에도 삽화 광고 가능
    ↓ 독자적 수익 창출
    ↓
독립 원작자로 전환
    ↓ 직접 원작 연재 → 코인 수익 + 포인트 풀 보유
```

- 2차 창작은 아직 유명세를 얻기 전의 작가가 성장하는 통로
- 포인트 현금화는 안 되지만, 인기가 쌓이면 삽화 광고로 직접 수익 가능
- 최종적으로 원작자로 전환하면 코인 수익까지 확보
