# 수익 모델

> 기획 문서

## 상태: 기획 중 (MVP 이후)

## 개요
3가지 수익 흐름: 독자 포인트 시스템, 원작자 광고/후원, 플랫폼 수익.

## 1. 독자/2차 창작자 포인트 시스템

### 포인트 획득
- 2차 창작(분기) 생성 시 원작 홍보 효과에 비례하여 포인트 지급
- 홍보 측정 기준: 분기를 통해 원작으로 유입된 독자 수, 분기의 engagement_score
- 포인트 = 원작 홍보 기여도 기반 (구체적 공식 추후 확정)

### 포인트 사용
- 유료 원작 에피소드 열람
- 코인으로 전환하여 결제

### 코인 결제 시스템
- 암호화폐 기반 결제 (사업자 등록 없이 운영 가능)
- 코인으로 유료 에피소드 구매
- 포인트 → 코인 전환 가능

## 2. 원작자 수익

### 유료 에피소드
- 원작자가 에피소드를 유료로 설정 가능
- 독자는 코인/포인트로 열람

### 삽화 광고
- 에피소드 내 삽화(이미지)에 외부 판매 링크 삽입 가능
- 원작자가 직접 광고주와 협의하여 삽화 광고 운영
- 플랫폼은 삽화 광고에 관여하지 않음 (원작자 자율)

### 월 정산
- 유료 에피소드 수익을 코인으로 월별 정산
- 정산 기준: 해당 월 에피소드 열람 건수 × 에피소드 가격

## 3. 플랫폼 수익

### 플랫폼 광고
- 페이지 내 배너/네이티브 광고 (원작자 광고와 별개)
- 광고 수익은 플랫폼에 귀속

### 수수료
- 유료 에피소드 거래 시 플랫폼 수수료 (비율 추후 확정)
