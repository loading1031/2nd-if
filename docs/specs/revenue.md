# 수익 모델

> 기획 문서

## 상태: 기획 중 (MVP 이후)

## 개요
돈의 흐름이 명확하게 분리된 구조:
- **독자 → 원작자**: 코인으로 직접 결제 (플랫폼 수수료 없음)
- **광고주 → 플랫폼**: 구글 애드센스 등 광고 수익
- **원작자 자율 광고**: 삽화 내 판매 링크 (플랫폼 비관여)

## 1. 독자 → 원작자 (코인 직접 결제)

### 구조
- 독자가 유료 에피소드를 코인(암호화폐)으로 결제
- 코인이 원작자 지갑으로 **직접 전송** (플랫폼 수수료 없음)
- 플랫폼은 중개만 하고 돈을 만지지 않음

### 결제 플로우
1. 원작자: 에피소드에 코인 가격 설정
2. 독자: 유료 에피소드 클릭 → 코인 결제 요청
3. 결제 게이트웨이(NOWPayments 등)가 독자 → 원작자 지갑으로 전송
4. 결제 확인 후 에피소드 열람 권한 부여

### 원작자 설정
- 지갑 주소 등록 (프로필에서 설정)
- 에피소드별 가격 설정 (무료/유료 선택)

## 2. 2차 창작자 포인트 시스템

자세한 내용은 [[point-system]] 참조.

- 각 작품(Work)마다 고유한 포인트 풀이 존재
- 원작의 인기 통계에 따라 풀이 생성됨 (원작자의 홍보 예산)
- 2차 창작자는 홍보 기여도에 따라 포인트 수령
- 포인트로 유료 에피소드 열람 가능 (코인 대신)
- **포인트로 열람된 건은 원작자의 포인트 풀에서 차감** → 원작자가 홍보비로 지출하는 것
- 플랫폼 내에서만 순환 (현금화 불가)

## 3. 원작자 삽화 광고 (자율)

- 에피소드 내 삽화(이미지)에 외부 판매 링크 삽입 가능
- 원작자가 직접 광고주와 협의
- 플랫폼은 관여하지 않음, 수수료 없음
- 에피소드 본문 내 이미지에 링크 기능으로 구현

## 4. 플랫폼 수익 (구글 광고)

- Google AdSense로 페이지 내 광고 노출
- 원작자 삽화 광고와 별개
- 초기 플랫폼 운영비 충당 목적
- 광고 위치: 에피소드 사이, 사이드바, 목록 페이지 등

## 핵심 포인트
- **플랫폼은 코인 거래에서 수수료를 받지 않는다**
- 플랫폼 수익은 오직 구글 광고
- 원작자는 코인 직접 수령 + 삽화 광고 자율 운영 + 포인트 풀로 홍보비 지출
- 2차 창작자는 포인트로 보상 (플랫폼 내 순환)
- 포인트 열람 = 원작자가 홍보비를 쓴 것 (원작자-독자가 함께 홍보)
