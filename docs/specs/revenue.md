# 수익 모델

> 기획 문서

## 상태: 보류 (현 제품 범위 밖)

> 아래 결제·광고·포인트 내용은 과거 제안이며 현재 승인된 수익 모델이 아니다. 현재는 유료 열람·PG·결제·유료 지표를 도입하지 않는다. 설정집 제작자의 무료/유료 배포 권한은 [설정집과 시각 에셋](setting-book.md)에 기록하며, 결제 구현은 후속 기획이다.

## 개요
돈의 흐름이 명확하게 분리된 구조:
- **독자 → 원작자**: Polygon USDC/USDT 직접 결제 (플랫폼 수수료 없음)
- **광고주 → 플랫폼**: 구글 애드센스 등 광고 수익
- **원작자 자율 광고**: 삽화 내 판매 링크 (플랫폼 비관여)

## 1. 독자 → 원작자 (스테이블코인 직접 결제)

### 체인 및 토큰
- **네트워크**: Polygon (가스비 거의 없음, 소액 결제 적합)
- **지원 토큰**: USDC, USDT (스테이블코인만)
- **지갑**: MetaMask

### 결제 플로우
1. **원작자**: 프로필에서 Polygon 지갑 주소 등록
2. **원작자**: 에피소드에 USDC/USDT 가격 설정 (예: 0.5 USDC)
3. **독자**: 유료 에피소드 클릭 → "결제하기" 버튼
4. **독자**: MetaMask 팝업 → Polygon 네트워크에서 작가 지갑으로 직접 송금
5. **플랫폼**: 트랜잭션 해시로 결제 확인 (Polygon RPC 조회)
6. **플랫폼**: 확인 후 에피소드 열람 권한 부여

### 결제 확인 방식
- 독자가 MetaMask에서 송금 후 트랜잭션 해시 자동 캡처
- Django에서 Polygon RPC로 트랜잭션 상태 확인
  - to 주소 = 작가 지갑
  - amount >= 에피소드 가격
  - 토큰 = USDC 또는 USDT
  - status = success
- 확인 완료 시 `EpisodePurchase` 레코드 생성

### 원작자 설정
- 지갑 주소 등록 (User.wallet_address, Polygon 주소)
- 에피소드별 가격 설정 (Episode.price, 토큰 단위)
- 지갑 미등록 시 유료 에피소드 생성 불가

### 데이터 모델

#### EpisodePurchase
| 필드 | 타입 | 설명 |
|------|------|------|
| episode | FK(Episode) | 구매한 에피소드 |
| buyer | FK(User) | 구매자 |
| tx_hash | CharField(66) | Polygon 트랜잭션 해시 (unique) |
| token | CharField(10) | "USDC" 또는 "USDT" |
| amount | DecimalField | 결제 금액 |
| confirmed | BooleanField | 트랜잭션 확인 여부 |
| created_at | DateTimeField | 결제 시각 |

## 사용자 플로우

### 결제 - 정상
1. 독자: 유료 에피소드 클릭 → 결제 모달 표시 (가격, 작가 지갑, 토큰 선택)
2. 독자: MetaMask 연결 → Polygon 네트워크 확인/전환
3. 독자: 결제 승인 → 트랜잭션 전송
4. 플랫폼: 트랜잭션 확인 중 로딩 → 확인 완료 → 에피소드 열람

### 결제 - 에러
5. MetaMask 미설치 → 설치 안내 링크
6. 잔액 부족 → "잔액이 부족합니다" 에러
7. 네트워크 틀림 → Polygon 전환 요청
8. 트랜잭션 실패 → "결제에 실패했습니다. 다시 시도해주세요."
9. 이미 구매한 에피소드 → 바로 열람 (중복 결제 방지)

### 작가 설정 - 정상
10. 작가: 프로필 → 지갑 주소 입력 → 저장
11. 작가: 에피소드 작성 → 유료 토글 → 가격 입력

### 작가 설정 - 에러
12. 지갑 주소 미등록 상태에서 유료 에피소드 생성 → "먼저 지갑 주소를 등록하세요" 안내

## 3. 원작자 삽화 광고 (자율)

- 에피소드 내 삽화(이미지)에 외부 판매 링크 삽입 가능
- 원작자가 직접 광고주와 협의
- 플랫폼은 관여하지 않음, 수수료 없음
- 에피소드 본문 내 이미지에 링크 기능으로 구현

## 4. 플랫폼 수익 (구글 광고, MVP 이후)

- Google AdSense로 페이지 내 광고 노출
- 초기 플랫폼 운영비 충당 목적

## 핵심 포인트
- **플랫폼은 코인 거래에서 수수료를 받지 않는다**
- 독자 → 작가 직접 송금 (플랫폼은 트랜잭션 확인만)
- 스테이블코인(USDC/USDT)만 지원 (가격 변동 리스크 없음)
- Polygon 네트워크 (가스비 거의 0)
