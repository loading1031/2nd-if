# 복사 방지 시스템

> 기획 문서

## 상태: 기획 완료

## 개요
복사를 완전히 차단하지 않고, 복사 시 출처 URL을 자동 삽입하여 홍보 효과로 전환한다.
유료 콘텐츠는 워터마크로 추가 보호. 비로그인 유저도 세션/핑거프린트로 추적.

## 복사 전략: 출처 삽입 (Medium 방식)

- 텍스트 복사를 허용하되, 클립보드에 출처 URL을 자동 추가
- 복사된 내용이 SNS에 퍼지면 홍보 효과

```
[복사된 텍스트]

— 「달빛 아래의 약속」 제25화
https://2nd-if.com/stories/1/episodes/25/
```

## Zero-width 워터마크

- 텍스트에 보이지 않는 유니코드 문자로 사용자 식별자 인코딩
- 유출 시 누가 복사했는지 추적 가능
- ZWS(U+200B) = 0, ZWNJ(U+200C) = 1, ZWJ(U+200D) = 구분자

### 워터마크 식별자 우선순위
1. 로그인 유저 → user.id
2. 세션 있음 → session.session_key
3. 핑거프린트 → visitor_id (세션 만료 후에도 추적)

## 시각적 워터마크 (유료 에피소드만)

- 본문 위에 반투명 닉네임 오버레이
- 스크린샷 찍어도 누가 찍었는지 보임
- 무료 에피소드는 적용하지 않음

## 핑거프린트 블랙리스트

- 제재된 유저의 핑거프린트를 블랙리스트에 저장
- 새 계정 가입/로그인 시 블랙리스트 비교 → 밴 회피 방지
- FingerprintJS 라이브러리 사용

### 데이터 모델

#### FingerprintLog
| 필드 | 타입 | 설명 |
|------|------|------|
| user | User (nullable) | 로그인 유저 (비로그인이면 null) |
| fingerprint | string(64) | 브라우저 핑거프린트 |
| created_at | datetime | 기록 시점 |

#### FingerprintBlacklist
| 필드 | 타입 | 설명 |
|------|------|------|
| fingerprint | string(64) | 차단된 핑거프린트 (unique) |
| reason | text | 차단 사유 |
| created_at | datetime | 차단 시점 |

## 사용자 플로우

### 정상
1. 독자가 에피소드 텍스트 복사 → 클립보드에 출처 URL 포함
2. SNS에 붙여넣기 → 출처 링크로 트래픽 유입

### 추적
3. 로그인 유저 복사 → zero-width 워터마크에 user.id 포함
4. 비로그인 유저 복사 → 세션/핑거프린트로 추적
5. 유출 콘텐츠에서 워터마크 추출 → 유출자 식별

### 제재
6. 관리자가 유저 제재 → 핑거프린트 블랙리스트 추가
7. 제재 유저가 새 계정 생성 시도 → 핑거프린트 비교 → 가입 거부
8. 제재 유저가 다른 계정으로 로그인 시도 → 핑거프린트 비교 → 로그인 거부
