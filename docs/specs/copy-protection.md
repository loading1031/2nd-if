# 복사 방지 시스템

> 기획 문서

## 상태: 기획 완료

## 개요
복사를 완전히 차단하지 않고, 복사 시 출처 URL을 자동 삽입하여 홍보 효과로 전환한다.
유료 콘텐츠는 워터마크로 추가 보호. 비로그인 유저도 세션/핑거프린트로 추적.

## 복사 전략: 출처 삽입 (Medium 방식)

- 텍스트 복사를 허용하되, 클립보드에 출처 URL을 자동 추가
- 복사된 내용이 SNS에 퍼지면 홍보 효과

```
[복사된 텍스트]

— 「달빛 아래의 약속」 제25화
https://2nd-if.com/stories/1/episodes/25/
```

## Zero-width 워터마크

- 텍스트에 보이지 않는 유니코드 문자로 사용자 식별자 인코딩
- 유출 시 누가 복사했는지 추적 가능
- ZWS(U+200B) = 0, ZWNJ(U+200C) = 1, ZWJ(U+200D) = 구분자

### 워터마크 식별자 우선순위
1. 로그인 유저 → user.id
2. 세션 있음 → session.session_key
3. 핑거프린트 → visitor_id (세션 만료 후에도 추적)

## 시각적 워터마크 (유료 에피소드만)

- 본문 위에 반투명 닉네임 오버레이
- 스크린샷 찍어도 누가 찍었는지 보임
- 무료 에피소드는 적용하지 않음

## 핑거프린트 블랙리스트

- 제재된 유저의 핑거프린트를 블랙리스트에 저장
- 새 계정 가입/로그인 시 블랙리스트 비교 → 밴 회피 방지
- FingerprintJS 라이브러리 사용

### 데이터 모델

#### FingerprintLog
| 필드 | 타입 | 설명 |
|------|------|------|
| user | User (nullable) | 로그인 유저 (비로그인이면 null) |
| fingerprint | string(64) | 브라우저 핑거프린트 |
| created_at | datetime | 기록 시점 |

#### FingerprintBlacklist
| 필드 | 타입 | 설명 |
|------|------|------|
| fingerprint | string(64) | 차단된 핑거프린트 (unique) |
| reason | text | 차단 사유 |
| created_at | datetime | 차단 시점 |

## 사용자 플로우

### 워터마크 - 정상
1. 텍스트에 user.id로 워터마크 삽입 → 추출 시 동일 ID 반환
2. 비로그인 유저 → 세션 키로 워터마크 삽입 → 추출 시 동일 키 반환
3. 빈 텍스트 → 워터마크 없이 빈 문자열 반환
4. 특수문자/이모지 포함 텍스트 → 워터마크 정상 삽입/추출

### 워터마크 - 엣지
5. 매우 긴 식별자 → 정상 인코딩/디코딩
6. 워터마크 없는 텍스트에서 추출 시도 → None 반환
7. 워터마크가 일부 손상된 텍스트 → None 반환 (에러 아님)

### 핑거프린트 블랙리스트 - 정상
8. 정상 핑거프린트로 가입 → 성공
9. 정상 핑거프린트로 로그인 → 성공
10. 접속 시 FingerprintLog 기록됨

### 핑거프린트 블랙리스트 - 제재
11. 블랙리스트된 핑거프린트로 가입 시도 → 거부
12. 블랙리스트된 핑거프린트로 로그인 시도 → 거부
13. 관리자가 제재 → 해당 유저의 핑거프린트가 블랙리스트에 추가됨

### 핑거프린트 - 엣지
14. 핑거프린트 없이 요청 → 정상 처리 (차단 안 함, 로그만 안 남김)
15. 같은 핑거프린트로 여러 계정 → 모두 기록됨
