# 신고/모더레이션

> 기획 문서

## 상태: 기획 중 (MVP 이후)

## 개요
부적절한 콘텐츠 및 표절 의혹에 대한 신고와 처리 시스템.

## 신고 유형

| 유형 | 설명 | 처리 주체 |
|------|------|----------|
| 외부 작품 표절 | 다른 플랫폼/작품의 내용을 도용 | 플랫폼 운영 |
| 원작 내 표절 | 원작 이후 전개를 그대로 복붙 (자동 검사 우회) | 원작자 + 플랫폼 |
| 부적절한 콘텐츠 | 욕설, 비방, 불법 내용, 혐오 표현 | 플랫폼 운영 |
| 스팸/도배 | 의미 없는 내용 반복 게시 | 플랫폼 운영 |
| 저작권 침해 | 이미지, 삽화 등의 무단 사용 | 플랫폼 운영 |

## 신고 플로우

```
독자/작가가 에피소드/작품 신고
    ↓
신고 유형 선택 + 사유 입력
    ↓
신고 접수 (status: pending)
    ↓
운영팀 검토 (또는 자동 필터링)
    ↓
판정: 무혐의 / 경고 / 비공개 / 계정 제재
    ↓
신고자 + 피신고자에게 결과 알림
```

## 신고 가능 대상
- 에피소드 (원작 및 분기 모두)
- 작품 전체
- 댓글 (추후 댓글 기능 추가 시)

## 제재 수준

| 수준 | 조치 |
|------|------|
| 무혐의 | 조치 없음 |
| 경고 | 작가에게 경고 알림 |
| 콘텐츠 비공개 | 해당 에피소드/작품 비공개 처리 |
| 계정 정지 | 일정 기간 작성 권한 제한 |
| 영구 정지 | 계정 영구 차단 |

## 표절 신고 특례
- [[plagiarism]] 자동 검사에서 승인된 분기는 원작 내 표절 신고 대상에서 제외
- 외부 작품 표절은 자동 검사 대상이 아니므로 신고로만 처리

## 데이터 모델

### 신고 (Django ORM)
| 필드 | 타입 | 설명 |
|------|------|------|
| reporter | User | 신고자 |
| target_type | enum | episode / work |
| target_id | int | 신고 대상 ID |
| report_type | enum | plagiarism_external / plagiarism_internal / inappropriate / spam / copyright |
| reason | text | 신고 사유 |
| status | enum | pending / reviewing / resolved / dismissed |
| resolution | text | 처리 결과 (null=미처리) |
| resolved_by | User | 처리자 (null=미처리) |
| created_at | datetime | 신고 시점 |
| resolved_at | datetime | 처리 시점 |

## 의존성
- [[auth]] — 신고자/피신고자 식별
- [[story]] — 신고 대상 에피소드/작품
- [[branch]] — 분기 관련 표절 신고
- [[plagiarism]] — 자동 검사와 연동 (승인된 분기 제외)
