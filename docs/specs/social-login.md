# 소셜 로그인

> 기획 문서

## 상태: 기획 완료

## 개요
Google, X(Twitter), Instagram 3개 소셜 로그인을 제공한다.
기존 이메일/비밀번호 가입은 유지하되, 소셜 로그인을 권장한다.

## 소셜 프로바이더

| 프로바이더 | OAuth | 타겟 유저 |
|-----------|-------|----------|
| Google | OAuth 2.0 | 범용 (글로벌) |
| X (Twitter) | OAuth 2.0 | 작가 홍보/팬 소통 |
| Instagram | Meta OAuth | 삽화/표지 홍보, 북스타그램 |

## 기술: django-allauth

django-allauth를 사용하여 소셜 로그인을 구현한다.
- 여러 프로바이더를 통일된 인터페이스로 관리
- 소셜 계정 연결/해제
- 동일 이메일 자동 연결

## 사용자 플로우

### 소셜 로그인 - 정상
1. 비회원 → "Google로 로그인" 클릭 → OAuth 인증 → 자동 가입 + 로그인 → 홈
2. 비회원 → "X로 로그인" 클릭 → OAuth 인증 → 자동 가입 + 로그인 → 홈
3. 비회원 → "Instagram으로 로그인" 클릭 → OAuth 인증 → 자동 가입 + 로그인 → 홈
4. 기존 회원 → 소셜 로그인 → 동일 이메일이면 기존 계정에 연결
5. 소셜 로그인 시 닉네임 자동 설정 (소셜 프로필에서 가져옴)

### 소셜 로그인 - 에러
6. 소셜 인증 취소 → 로그인 페이지로 복귀
7. 소셜 계정에 이메일 없음 → 이메일 입력 요청

### 신고/제재 연동
8. 소셜 계정 ID + 핑거프린트로 이중 식별
9. 밴된 소셜 계정으로 재로그인 → 차단

## 데이터 모델

django-allauth가 자동 관리:
- `SocialAccount` — 소셜 계정 정보
- `SocialToken` — OAuth 토큰
- `SocialApp` — 프로바이더 설정 (admin에서 등록)
