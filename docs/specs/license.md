# 콘텐츠 라이선스

> 기획 문서

## 상태: 기획 중

## 개요
원작자가 작품 생성 시 2차 창작의 허용 범위를 설정하는 라이선스 시스템.
MIT 라이선스처럼 명확한 조건을 선택하는 방식.

## 라이선스 옵션

| 옵션 | 설명 |
|------|------|
| 자유 분기 허용 | 누구나 분기 가능, 상업적 이용 가능 |
| 비상업적 분기만 허용 | 분기 가능하되 상업적 이용 금지 |
| 동일 조건 변경 허락 | 분기 시 동일한 라이선스 적용 필수 |
| 분기 금지 | 2차 창작 불허 (읽기만 가능) |

## 적용 시점
- 작품 생성 시 필수 선택
- 이후 변경 가능 (단, 이미 생성된 분기에는 소급 적용 안 됨)

## 분기 시 검증
- 분기 생성 요청 시 원작의 라이선스 확인
- "분기 금지" 작품에서는 분기 버튼 비활성화
- 라이선스 조건을 분기 생성 화면에 명시
