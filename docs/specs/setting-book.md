# 설정집과 시각 에셋

> 2026-10-17 변경: Blender 기반 장면·화면 반응 계획은 폐기했다. 시각 에셋 방향은 [작품별 수집 도감](collection-encyclopedia.md)과 이슈 #15/#33으로 대체한다. 아래 Blender 관련 내용은 과거 기획 이력이며 현재 구현 요구사항이 아니다. 설정집 권한·버전 및 텍스트 독서 요구사항은 별도 유지한다.

- 작성일: 2026-10-16
- 상태: 초안 (핵심 권한·버전·키 결정 반영)
- 관계: [platform.md](platform.md)의 설정집 요약. 관련 문서: [story.md](story.md), [license.md](license.md), [dynamic-reader.md](dynamic-reader.md)

## 결론

설정집은 작품과 별도로 제작·배포되는 창작물이다. 작품 작가는 설정집 전체를 채택한 뒤 필요한 항목을 작품별로 선택해 쓰고, 설정집의 용어와 Blender 에셋은 명시적인 키와 버전으로 연결한다.

## 결정 사항

| 항목 | 결정 | 이유 |
|---|---|---|
| 제작자 | 소설 작가와 별개로 설정을 제작하는 창작자 역할을 둔다. | 소설 집필 외 창작 기여를 허용 |
| 구성 | 국가·역사·지형 등 정적 설정과 Blender 캐릭터·사물·배경 등 시각 에셋을 담는다. | 설정과 시각 표현을 재사용 가능하게 함 |
| 배포 | 제작자가 무료 또는 유료 배포를 선택한다. 현재 결제는 범위 밖이며 나중 확장을 고려한다. | 제작자 자율성 |
| 채택 | 구매/이용 권한은 설정집 전체 단위다. 각 작품은 그 안의 필요한 항목만 골라 채택한다. | 간단한 권한 단위와 세밀한 작품 구성 |
| 재사용 | 향후 구매한 작가는 설정집을 자신의 여러 작품에 재사용할 수 있다. 독자는 별도 설정집 이용권 없이 작품에 포함된 에셋을 볼 수 있다. | 작품 간 창작과 독자 열람 지원 |
| 키 | 에셋 키를 `색상`, `사물 이름`, `배경 이름`으로 분리하고 해당되는 값만 채운다. | 용어 기반 검색·매칭 |
| 흑백·색상 | 시각 에셋은 흑백 기본형을 필수로 제공한다. 색상 변형은 선택으로 추가할 수 있다. | 기본 표현 보장, 제작자 선택적 확장 |
| 색상 사전 | 모든 사용자가 공용 색상 사전을 기본으로 이용한다. 작가와 설정집 제작자는 별칭을 추가·매핑할 수 있다. | 색상 표현 정규화와 사용자 창작 지원 |
| 충돌 | 설정집 채택 단계에서 용어 충돌을 감지해 알린다. 경고는 선택을 막지 않는다. 같은 표현이 여러 에셋과 충돌하면 작품 작가가 문맥별로 표현-에셋 매핑을 지정하며, 지정하지 않은 표현에는 에셋을 자동 표시하지 않는다. | 충돌을 투명하게 알리되 임의 선택과 창작 제한을 피함 |
| 버전 | 작품은 채택한 설정집 버전을 고정한다. 업데이트는 작품 작가가 검토하고 명시적으로 적용한다. | 공개 작품의 재현성과 안정성 |
| 라이선스 | 사용 중인 버전의 라이선스는 바꿀 수 없다. 조건 변경은 새 버전/설정집으로 배포한다. | 기존 작품의 권리 조건 보존 |
| 상업 이용 | 무료 사용만 허용하는 설정집도 무료 작품에서는 쓸 수 있다. 그런 설정집을 채택한 작품은 포함된 동안 유료화할 수 없다. 상업 이용 허용 버전만 채택하거나 설정집을 제거해야 유료화를 고려할 수 있다. | 설정집 제작자의 사용 범위 존중 |

## 에셋 키와 매칭

에셋 제작자는 Blender에서 만든 시각 요소에 적용할 속성 키를 등록한다. 예를 들어 흰 늑대의 색상 변형은 `색상=흰색`, `사물 이름=늑대`를 가질 수 있다. 색상 키가 없는 늑대 에셋은 색상 묘사에 관계없이 늑대 명사에 매칭된다. 색상 변형이 있으면 작품 작가가 승인한 색상 표현과 함께 매칭한다. 맞는 색상 변형이 없으면 흑백 기본형을 사용한다.

색 표현은 공용 사전의 표준 HEX 색상 값에 연결하고 여러 동의어를 허용한다. 작품 작가 또는 설정집 제작자가 별칭을 더할 수 있다. HEX 문자열의 구체 형식(예: `#RRGGBB`)은 구현 명세에서 확정한다. 작품 고유 별칭은 해당 작품의 매핑으로 제한하며, 설정집 별칭이 작품에서 승인 없이 기존 표현의 뜻을 덮지 않는다.

설정집을 작품에 추가하거나 작품 용어를 매핑할 때 충돌을 검사한다. 충돌 목록은 정규화된 용어별로 묶고, 출처 설정집·버전·키 종류(색상/사물/배경)·매칭된 에셋 미리보기·HEX 값(색상일 때)을 나란히 보여주는 방식을 제안한다. 경고는 채택을 막지 않는다.

같은 표현이 서로 다른 에셋에 연결되어도 시스템이 `first()` 하나를 임의 선택하지 않는다. 작가는 편집기에서 각 텍스트 표현이 쓸 에셋을 문맥별로 승인한다. 이 매핑은 해당 작품/표현 범위에만 저장하고 원문은 바꾸지 않는다. 매핑하지 않은 충돌 표현은 독자 화면에서 임의 에셋을 열지 않는다. 충돌이 아닌 표현은 기존처럼 연결된 에셋을 탭해 연다. 이 방식은 여러 에셋을 작품 안에서 모두 사용할 수 있게 하면서 독자에게 무작위 선택을 노출하지 않는다.

## 버전과 이용 권한

```text
설정집 제작·배포
  → 고정 버전 게시 (라이선스 포함)
  → 작가가 설정집 전체 이용 권한 보유
  → 작품별 세부 항목 선택·용어 매핑
  → 작품은 해당 설정집 버전 고정
  → 새 버전 공개 시 작가가 검토 후 갱신 여부 선택
```

설정집의 무료/유료 배포와 작품의 상업적 이용 허용은 별도 조건이다. 독자는 작품을 볼 때 설정집에 대해 별도 결제하지 않는다. 작품의 향후 유료화 자격은 해당 작품이 채택한 모든 설정집 버전의 상업 이용 조건을 만족해야 한다.

## 에셋 저장·전달 구조 제안

파일 저장과 용어 검색은 별개 문제다. 현재 독자 기능은 텍스트를 눌러 정적 그림을 보는 것이므로, Blender 씬을 브라우저에서 매번 열거나 매 클릭 때 DB에서 검색할 필요가 없다. 권장 구성을 다음처럼 구체화한다.

- 독자는 Blender 작업 원본 `.blend`를 내려받지 않고, 제작자가 Blender에서 렌더한 흑백 기본 이미지와 선택 색상 변형(WebP 우선, PNG 대체)을 사용한다. 현 범위에 원본 다운로드는 포함하지 않는다. 향후 원본 배포를 지원한다면 설정집 제작자가 배포 여부와 허용 범위를 정하도록 별도 라이선스 옵션을 둔다. 자동 Blender 렌더 farm이나 독자 브라우저 내 Blender 렌더링은 범위에 넣지 않는다.
- 객체 스토리지(S3)는 이미지 파일을 저장하고 DB는 설정집/버전, 키, 변형, object key, MIME type, 크기, 해시를 저장한다. DB에 바이너리 파일을 넣지 않는다. DB는 키 조합으로 후보를 찾고, 실제 이미지 바이너리는 object storage/CDN에서 전달한다.
- 업로드 구현은 서버가 권한과 정해진 object key를 발급한 제한 시간 사전 서명 URL로 브라우저가 S3에 직접 보내는 방법을 권고한다. 업로드 완료 후 서버가 MIME type·크기·해시를 확인하고 DB 메타데이터를 확정한다.
- 변경 불가능한 설정집 버전 경로에 파일을 둔다(예: `setting-book-id/version/asset-id/content-hash.webp`). 파일 교체는 기존 object key 덮어쓰기가 아니라 새 버전으로 발행한다.
- 발행 시 서버는 작품이 고정한 설정집 버전과 승인된 표현 매핑으로 페이지별 manifest를 만든다. 클릭은 manifest 안의 에셋 ID/전달 경로를 사용하므로 매번 용어 검색 DB를 조회하지 않는다.
- 공개 발행 이미지에는 CDN 캐시를 사용한다. 비공개 초안/비공개 작품은 짧은 만료의 서명 URL 등으로 접근을 제한한다. 링크 공개의 접근 방식과 향후 유료 라이선스 권한 검사는 실제 배포 설계에서 확인한다.
- 실제 독서 UI에는 렌더 이미지(WebP 우선, PNG 대체)를 제공한다. GLB/glTF를 통한 3D 탐색은 현재 클릭해서 그림을 보는 기능과 분리된 후속 선택지다.

```text
Blender 제작자
  └─ WebP/PNG 렌더 변형 업로드 → 제한 시간 업로드 URL → S3 객체 키
                                ↓
설정집 DB (용어·색상 키·버전·오브젝트 메타데이터)
  └─ 작품별 승인 매핑 → 발행 시 페이지 manifest → CDN 이미지
```

## 데이터 모델 영향

설정집, 불변 버전, 버전별 라이선스, 설정 항목, 에셋, 흑백 기본형/색상 변형, 색상 별칭, 작품별 채택 버전과 작품 용어 매핑이 필요하다. 구체적인 테이블 구조는 P2에서 검토한다.

## 구현 단계에서 정할 것

- 제작자 업로드의 WebP/PNG 크기·해상도·크롭 규격을 정한다.
- 공개·링크 공개·비공개 작품에 따른 CDN 접근 통제와 향후 유료 라이선스 검증 방식을 정한다.
