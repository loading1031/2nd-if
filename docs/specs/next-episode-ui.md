# 다음 화 선택 UI 및 가중치 정렬

> 기획 문서

## 상태: 기획 완료

## 개요
독자가 한 화를 다 읽고 "다음 화"로 넘어가는 시점에, 원작 다음 화 + 2차 창작 분기들을 가중치 순으로 보여주는 핵심 UI.

## 표시 구조

```
┌─────────────────────────────────┐
│  [원작] 제31화: 원작 제목        │  ← 항상 최상단 고정
│  by 원작자  ♥ 1,234  👁 5,678   │
├─────────────────────────────────┤
│  [분기] 제31화: 다른 결말        │  ← engagement_score 순 정렬
│  by 2차작가A  ♥ 456  👁 2,100   │
├─────────────────────────────────┤
│  [분기] 제31화: 만약 그때...     │
│  by 2차작가B  ♥ 123  👁 890     │
├─────────────────────────────────┤
│  [분기] 제31화: 히든 엔딩        │
│  by 2차작가C  ♥ 45   👁 320     │
└─────────────────────────────────┘
│                                 │
│    + 여기서 새 분기 만들기       │  ← 분기 생성 버튼 (조건 충족 시)
└─────────────────────────────────┘
```

## 정렬 규칙
1. **원작 다음 화**: 항상 최상단 고정 (is_original = true)
2. **2차 창작 분기**: engagement_score 내림차순
3. 분기가 없으면 원작 다음 화만 표시 (일반 소설 읽기와 동일)

## 지표 분리

| 위치 | 지표 | 의미 |
|------|------|------|
| Django ORM (Episode) | avg_rating | 에피소드 별점 평균 (품질 평가) |
| Neo4j (NEXT 엣지) | visit_count | 이 경로로 이동한 유효 횟수 |

## engagement_score 계산

```
engagement_score = visit_count
```

- `visit_count`: 이 경로로 이동한 **유효** 횟수
- 단순하게 visit_count 기반 정렬 (추후 추가 지표 반영 가능)

## 가중치 업데이트 조건

독자가 A→B 경로로 이동할 때:
1. B 에피소드로 이동
2. B의 별점 확인:
   - **별점 3점 이하** → visit_count 증가하지 않음 (저품질 필터)
   - **별점 미등록 또는 4점 이상** → visit_count +1
3. 낮은 평점의 경로는 자연스럽게 추천에서 밀림

## 표시 조건
- 분기점은 해당 에피소드까지 모두 읽은 독자에게만 표시
- 미읽은 독자에게는 원작 다음 화만 자동 연결 (스포일러 방지)

## 카드 표시 정보
| 항목 | 설명 |
|------|------|
| 라벨 | [원작] 또는 [분기] |
| 에피소드 번호 | 분기 시작점 기준 화 번호 |
| 제목 | 에피소드 제목 |
| 작성자 | by {닉네임} |
| 별점 | ★ {avg_rating} (에피소드 품질) |
| 이동 횟수 | 👁 {visit_count} (유효 이동만) |

## HTMX 구현 방향
- 에피소드 본문 하단에 다음 화 선택 영역
- `hx-get`으로 다음 화 목록 로드 (Neo4j에서 가중치 순 조회)
- 다음 화 클릭 시 `hx-post`로 visit_count 업데이트 + 페이지 이동
