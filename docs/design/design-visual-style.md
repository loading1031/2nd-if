## 한 줄 요약

**"크림 양피지 위의 검은 잉크 드래곤."** 중세 필사본의 물리적 페이지 감각을 Canvas + Pretext로 재구성한 읽기 경험.

## 팔레트

| 토큰 | 값 | 용도 |
|---|---|---|
| `--paper` | `#f4eee0` | 스프레드 배경 (양피지) |
| `--paper-shadow` | `#e8dfc8` | 페이지 접힘 내부/여백 그라디언트 끝점 |
| `--ink` | `#2a1a0a` | 본문 글자 (다크 워밍 브라운, 순수 #000 아님) |
| `--ink-bold` | `#1a0f05` | 드롭캡/헤딩 |
| `--ink-mute` | `#6b5940` | 각주/캡션 |
| `--accent-rubric` | `#a42a1c` | 장 첫 글자/인용(중세 rubric 레드) |
| `--accent-gold` | `#c89c3a` | 드물게 — 장 구분 장식에만 |

금지: 네온, 순수 #000, 순수 #fff, 그라디언트(2색 이상), 채도 높은 컬러.

## 타이포그래피

| 역할 | 폰트 | 크기 | 근거 |
|---|---|---|---|
| 본문 | EB Garamond 또는 Cormorant Garamond | 18–20px | 고전 세리프, 무료, 한글은 본명조로 매칭 |
| 드롭캡 | UnifrakturMaguntia 또는 Furia III | 본문 × 3.5 | 블랙레터/아르누보 — 필사본 감성 |
| 장 헤딩 | Cinzel 또는 IM Fell DW Pica | 28–32px | 로마네스크 대문자 |
| 한글 본문 | Nanum Myeongjo 또는 본명조 | 18–20px | 서양 세리프와 무게감 매칭 |

행간 1.7~1.8. 자간 약간 여유(+0.01em). 가로폭은 62~68자 (중세 단일 컬럼 감성).

## 일러스트 제작 규칙

### 무조건

1. **배경 투명 PNG**. 배경색을 일러스트에 칠해서 내보내지 않음.
2. **단일 톤 잉크** 또는 **얇은 라인아트 + 얇은 워시** 두 스타일만.
3. 해상도 1600–2400px 긴 변. Retina용.
4. 캐릭터/오브젝트는 프레임 정중앙이 아니라 **한쪽으로 치우치게** 배치 — 텍스트 공간을 남기기 위함.

### 금지

- 그라디언트 (2색 이상)
- 카툰 얼굴 (일본 애니 스타일, 픽사 스타일 모두)
- 사진합성/3D 렌더링 질감
- 배경이 있는 장면화(풍경/하늘 포함 이미지) — 배경은 항상 양피지 그 자체

### 스타일 매트릭스 (장르별 스킨 팩 매칭)

| 장르 | 레퍼런스 | 잉크 톤 | 허용 악센트 |
|---|---|---|---|
| fantasy | `01, 43` (Pretext 드래곤, Harley MS) | 순 검정 실루엣 | 없음 (모노톤) |
| romance | `20, 50` (Rackham, Dulac) | 세피아 라인아트 | 아이보리 워시 |
| horror | `22, 30` (Rackham skeleton, Beardsley) | 순 검정 + 크로스해칭 | 없음 |
| daily | `20` (Rackham) 풍 | 회갈색 라인 | 담홍 워시 |
| sf | `30` 변형 (Beardsley 기하) | 순 검정 + 흰선 | 터쿼이즈 1포인트 |
| mystery | `50, 51` (Dulac 밤) | 인디고 라인아트 | 문라이트 실버 |
| history | `41, 45` (Book of Hours) | 버밀리온 + 울트라마린 | 금박 (1포인트) |

## 페이지 레이아웃

### 스프레드 (1280×800 기준)

```
┌──────────────┬──────────────┐
│              │              │
│  [일러스트]    │    본문      │
│   좌상단      │   오른쪽 페이지 │
│              │              │
│   본문 좌하단  │              │
│              │              │
└──────────────┴──────────────┘
      좌 페이지        우 페이지
```

- 여백: 상 40px / 하 60px / 외측 48px / 내측(책등) 32px
- 드롭캡은 스프레드의 맨 첫 페이지에만
- 페이지 번호: 하단 외측, `IM Fell` 12px, 톤 `--ink-mute`
- 장 제목: 우측 페이지 상단 중앙, `Cinzel` small caps

### 모션

- 페이지 넘김 기본: 가로 슬라이드 600ms, ease-in-out
- 시네마틱 전환: 2400ms, 장면별 타임라인 (드래곤 돌진 → 먹물 산산조각 → 새 스프레드)
- 본문 등장: 페이드 인 400ms (스태거 없음 — 책은 한번에 보이니까)

## 금지/예외 사항

1. **모바일(<768px)은 이 가이드의 대상이 아니다.** 폰은 클래식 모드만. 디자인 에너지 투입 금지.
2. 다크 모드는 v2에서 — v1은 양피지만.
3. 사용자 정의 스킨 업로드는 v3. v1에서는 장르 팩만.
