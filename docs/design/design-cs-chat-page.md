### 섹션 설명

1. **헤더**: 페이지 제목 + 안내 문구
2. **채팅 영역**: 메시지 목록 (스크롤, 고정 높이 500px)
3. **SSE 상태 표시**: 연결 상태 인디케이터
4. **입력 영역**: 텍스트 입력 + 전송 버튼

## 사용 컴포넌트

### DaisyUI
- `chat`, `chat-start` — 관리자 말풍선 (좌)
- `chat-end` — 사용자 말풍선 (우)
- `chat-bubble`, `chat-bubble-primary` — 관리자 말풍선 스타일
- `chat-bubble-secondary` — 사용자 말풍선 스타일
- `tabs tabs-boxed` — 관리자 목록 상태 필터 탭
- `badge` — 미읽음 카운트
- `card` — 관리자 목록 대화방 카드
- `input input-bordered` — 메시지 입력
- `btn btn-primary` — 전송 버튼

### 상태별 UI

| 상태 | 전송 버튼 | 입력 필드 | 말풍선 |
|------|----------|----------|--------|
| 대기 | "전송" 텍스트 | 활성화 | - |
| 전송 중 | "전송 중..." 텍스트 | 비활성화 | - |
| 완료 | "전송" 텍스트 | 활성화 + 포커스 | 관리자 말풍선 표시 |
| 에러 | "전송" 텍스트 | 활성화 | 에러 메시지 표시 |
| 연결됨 | - | - | SSE 활성 (● 연결됨) |
| 연결 끊김 | - | - | SSE 비활성, 재연결 중 (● 연결 끊김) |

## 반응형

- **모바일**: 전체 너비, 채팅 영역 높이 축소 (h-[400px])
- **데스크톱**: max-w-3xl 중앙 정렬
