## 레이아웃

```
┌─────────────────────────────────────┐
│ Navbar                              │
├─────────────────────────────────────┤
│ 고객 상담 (h1)                       │
│ 설명 텍스트                          │
│                                     │
│ ┌─────────────────────────────────┐ │
│ │ [AI] 안녕하세요! 무엇을 도와...   │ │
│ │                                 │ │
│ │            [사용자] 로그인이 안돼 │ │
│ │                                 │ │
│ │ [AI] 비밀번호를 잊으셨다면...     │ │
│ │                                 │ │
│ │                                 │ │
│ │                                 │ │
│ └─────────────────────────────────┘ │
│                                     │
│ ┌──────────────────────────┐ ┌────┐ │

│                                     │
├─────────────────────────────────────┤
│ Footer                              │
└─────────────────────────────────────┘
```

### 섹션 설명

1. **헤더**: 페이지 제목 + 안내 문구
2. **채팅 영역**: 메시지 목록 (스크롤, 고정 높이 500px)
3. **입력 영역**: 텍스트 입력 + 전송 버튼

## 사용 컴포넌트

### DaisyUI
- `chat`, `chat-start`, `chat-end` — 좌/우 말풍선
- `chat-bubble`, `chat-bubble-primary` — AI 말풍선 (좌)
- `chat-bubble-secondary` — 사용자 말풍선 (우)
- `input input-bordered` — 메시지 입력
- `btn btn-primary` — 전송 버튼
- `loading loading-spinner` — 전송 중 로딩

### 상태별 UI

| 상태 | 전송 버튼 | 입력 필드 | 말풍선 |
|------|----------|----------|--------|
| 대기 | "전송" 텍스트 | 활성화 | - |
| 전송 중 | 스피너 | 비활성화 | AI 말풍선 생성 (빈 상태) |
| 스트리밍 중 | 스피너 | 비활성화 | AI 말풍선에 텍스트 실시간 추가 |
| 완료 | "전송" 텍스트 | 활성화 + 포커스 | 답변 완성 |
| 에러 | "전송" 텍스트 | 활성화 | 에러 메시지 표시 |

## 반응형

- **모바일**: 전체 너비, 채팅 영역 높이 축소 (h-[400px])
- **데스크톱**: max-w-3xl 중앙 정렬
