## 섹션 설명

1. **헤더**: 페이지 제목 + 안내 문구
2. **검색 입력**: 상단 고정, 키워드 실시간 필터링
3. **카테고리 탭**: DaisyUI tabs-boxed, 클릭 시 해당 카테고리만 표시
4. **FAQ 아코디언**: DaisyUI collapse, 질문 클릭 시 답변 토글
5. **하단 CTA**: "해결되지 않았나요?" 카드 + 1:1 채팅 링크

## 사용 컴포넌트

### DaisyUI
- `input input-bordered` — 검색 입력
- `tabs tabs-boxed` — 카테고리 탭
- `tab`, `tab-active` — 개별 탭 항목
- `collapse collapse-arrow` — FAQ 아코디언
- `collapse-title` — 질문 제목
- `collapse-content` — 답변 내용
- `card bg-base-200` — 하단 CTA 영역
- `btn btn-primary` — "1:1 채팅으로 문의하기" 버튼
- `alert alert-info` — 검색 결과 없음 안내

## 검색 동작

- 클라이언트 JS keyup 이벤트로 필터링 (서버 요청 없음)
- 질문 텍스트 + 답변 텍스트 모두 검색 대상
- 대소문자 무시
- 검색어 입력 시 카테고리 탭은 "전체"로 리셋
- 매칭 결과 없으면 "검색 결과가 없습니다" + 채팅 링크 표시

## 반응형

- **모바일**: 전체 너비, 카테고리 탭 가로 스크롤, 검색 입력 w-full
- **데스크톱**: max-w-3xl 중앙 정렬
