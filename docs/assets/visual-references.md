# 외형 참고 자료와 창작한 부분

현재 기본 스타일은 [흑백 명암](style-guide.md)이다. 아래 이미지는 형태와 재질 참고용이며, 아래 색상 관련 기록은 이전 컬러 시안의 이력이다.

이번 시안은 아래 이미지의 단순한 실루엣, 부드러운 색과 명암, 재질 표현을 참고해 SVG 경로를 직접 작성했다. 외부 SVG 경로 또는 비트맵을 삽입하지 않았다. 영약의 외형은 프로젝트의 창작 제안이며 이름에 고정된 공식 외형이 아니다.

| 참고 자료 | 참고한 요소 | 직접 정한 요소 |
|---|---|---|
| [Flaticon 인삼](https://www.flaticon.com/free-icon/ginseng_7774730) | 뿌리와 잎으로 알아보는 단순한 형태 | 설삼의 흰색, 통통한 몸체, 잔뿌리와 잎 배치 |
| [Giulia D’Andrea 수채화 물약](https://www.skillshare.com/de/classes/aquarell-illustration-erstelle-einen-satz-magischer-tranke/1626731469) | 따뜻한 색, 부드러운 유리병·액체 명암 | 공청석유의 병 형태, 우윳빛 액체와 마개; 환약 두 종류의 형태·표면 무늬 |
| [Pikbest 청옥 장신구](https://pikbest.com/png-images/qiantu-chinese-style-antique-exquisite-game-icon-green-jade-pendant_2691443.html) | 청록 옥과 붉은 매듭의 조합 | 둥근 사다리꼴 옥판, 구름 문양, 단순한 술 |

한 파일에는 대상 한 개만 담는다. 공청석유의 병은 영약을 담은 단일 아이템의 일부다. PNG 미리보기의 크림색 바탕은 검토용이며 SVG 배경은 투명하다. 현재 시안은 정적 SVG이다.

## 이전 컬러 시안의 색상 기준

형태는 참고 이미지의 둥근 실루엣을 유지한다. 색상은 기존 심장·늑대 SVG를 기준으로 채도와 명암 대비를 높이고 진한 외곽선을 사용한다. 대환단은 선명한 적색, 소환단은 짙은 황갈색, 공청석유의 병은 청록색, 설삼은 황금빛 뿌리와 녹색 잎, 청옥패는 짙은 비취색과 붉은 끈으로 수정했다. 병 몸체의 반투명 처리는 제거했다.
