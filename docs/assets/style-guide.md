# SVG 제작·평가 기준

## 현재 방향

도감은 Game-icons처럼 흑백 실루엣과 내부 선·여백으로 읽히는 아이콘을 우선한다. 외부 SVG는 원본 그대로 보관하고 저작자·출처·라이선스를 기록한다. 새로 만드는 도감 아이콘도 이 표현에 맞춘다. 아래 명암·재질 규칙은 기존 수제 SVG 시안의 기준이며 새 아이콘에 그라데이션을 강제하지 않는다.

형태는 아기자기하고 한눈에 읽히게 그린다. 색상은 쓰지 않고 흑백 명암으로 무게감과 재질을 표현한다. 밝은 파스텔색과 화려한 색 조합은 기본 스타일에서 제외한다. 기존 7개 에셋의 흑백 SVG가 출발점이다.

## 제작

- 한 파일에는 사물 또는 동물 하나만 담는다. 영약을 담은 병과 연결된 마개, 옥패의 매듭은 한 아이템의 구성 요소로 본다.
- 모든 색상은 R=G=B인 회색조로 지정한다. 바탕은 투명하게 두며 재질의 밝은 면은 실제 채움으로 그린다.
- 왼쪽 위에서 오는 빛을 기본으로 한다. 밝은 면·중간 면·그림자·접촉 그림자를 구분한다.
- 흰색과 짙은 회색은 형태를 읽게 하는 곳에 사용한다. 큰 면을 모두 검게 채워 세부가 묻히지 않게 한다.
- 약재 입자, 뿌리 주름, 털 방향, 혈관, 조각 문양처럼 대상의 특징을 설명하는 디테일을 더한다. 규칙적인 무늬를 반복해서 디테일을 대신하지 않는다.
- 환약은 거친 입자로, 옥은 새긴 문양과 무광의 면으로, 약재는 주름과 잎맥으로 구분한다. 유리병은 가장자리와 액체의 명도 차로 구분한다.
- 형태와 재질의 참고 자료를 기록한다. 특정 영약의 고정 외형인 것처럼 창작 디자인을 설명하지 않는다.
- SVG Creator의 렌더·시각 확인 과정을 거친 후 매핑 상태를 `ready`로 바꾼다.

## 평가 항목

1. 형태: 작은 크기에서도 어떤 대상인지 읽히고 개체 하나가 명확한가?
2. 명암: 밝은 면과 그림자로 부피와 무게가 전달되는가?
3. 재질·세부: 대상에 맞는 질감과 구조가 있고, 불필요한 반복 무늬가 없는가?
4. 완성도: 선이나 부위가 뜨거나 겹치지 않고, 벡터 확대와 실제 렌더에서 깨끗한가?

색상 조합은 평가 항목으로 사용하지 않는다. 단어 목록의 제작 완료 항목은 흑백 SVG를 기본 경로로 연결한다. 기존 컬러 파일은 비교용으로 보관한다.

## 반사광 수정

소환단·청옥패·설삼의 흰색 반사 띠, 밝은 점, 광택 테두리를 제거했다. 앞으로도 장난감처럼 보이는 반짝임은 기본으로 넣지 않고, 넓은 면의 명도 차와 재질 선으로 형태를 설명한다.
