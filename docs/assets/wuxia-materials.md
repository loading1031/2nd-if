# 무협 영약·약재·옥패 제작 방향

현재는 [흑백 명암 제작 기준](style-guide.md)을 적용한다. 아래 표의 색상은 초기 구상 기록이며 제작 시 색상 대신 밝기·질감·문양으로 차이를 표현한다.

형태가 없는 정파·사파·마교 등의 개념은 현재 제작 목록에 넣지 않는다. 무협 100개 목록은 실물로 표현할 수 있는 항목을 유지하고, 일반 생활용품·무기 부품 20개를 영약·약재 18개와 옥패 변형 2개로 교체했다.

## 먼저 제작할 후보

| 단어 | 형태 기준 | 그림 표현 제안 |
|---|---|---|
| 대환단 | 가상 영약, 외형은 작품마다 다름 | 살구빛 붉은 환약 한 알, 작은 약초 잎 압인 |
| 소환단 | 가상 영약, 외형은 작품마다 다름 | 꿀갈색의 납작한 환약 한 알, 짧은 약재 섬유 |
| 천년설삼 | 가상 약재, 외형은 작품마다 다름 | 희고 길게 갈라진 뿌리 하나, 가는 뿌리수염 |
| 만년설삼 | 천년설삼과 별도 제작 | 굵고 비틀린 흰 뿌리 하나, 옅은 청색 결 |
| 천년하수오 | 실물 하수오 뿌리를 바탕으로 한 가상 변형 | 적갈색 덩이뿌리 하나, 깊은 표면 주름 |
| 만년하수오 | 천년하수오와 별도 제작 | 짙은 자갈색 덩이뿌리 하나, 굵은 뿌리 갈래 |
| 천년영지 | 실물 영지를 바탕으로 한 가상 변형 | 적갈색 부채꼴 갓과 짧은 자루를 가진 버섯 한 개 |
| 만년영지 | 천년영지와 별도 제작 | 넓고 두꺼운 갓 하나, 촘촘한 동심원 무늬 |
| 공청석유 | 가상 액체 영약, 외형은 작품마다 다름 | 둥근 청록 유리병 하나에 담긴 우윳빛 액체 |
| 천년석유 | 가상 액체 영약, 공청석유와 관계는 작품별 확인 | 반투명한 유백색 액체 한 방울 |
| 옥패 | 실물 장신구를 참고 가능 | 구멍과 짧은 매듭이 있는 옥패 한 개 |
| 백옥패 | 옥패의 재질 변형 | 유백색 옥판 한 개, 얕게 새긴 무늬 |
| 청옥패 | 옥패의 재질 변형 | 청록색 옥판 한 개, 반투명한 가장자리 |

위 색상·무늬·형태 차이는 에셋 제작 제안이며 무협 전체에 통용되는 고정 설정이 아니다. 약효·연대·소속 문파는 이름만으로 자동 부여하지 않는다. 환약은 약병과 함께 그리지 않고 한 알만, 약재는 한 개체만 표현한다.

추가 후보는 설삼·하수오·황정·복령·산삼·천년산삼·적하수오·백하수오이며 전체 단어와 제작 상태는 [영약 목록](vocabulary/wuxia/elixirs.csv)과 [약재 목록](vocabulary/wuxia/herbs.csv)에서 관리한다. 세부 품종이나 연대가 다른 단어는 자동 동의어로 묶지 않는다.
