# AI 스토리 어시스턴트

> 아이디어 메모 (MVP 이후)

## 컨셉
유저가 세계관/등장인물을 입력하면 AI가 스토리 초안을 생성하고, 대화를 통해 디테일을 채워나가는 기능.

## 플로우
1. 유저: 세계관 구조, 등장인물, 설정 입력
2. AI: 스토리 초안 생성
3. 유저 ↔ AI: 챗 인터페이스로 디테일 수정/보완
4. 유저: 확정 후 에피소드로 발행

## 기술 방향
- Dify Chatflow 활용 (CS 채팅과 동일 패턴)
- Knowledge Base에 세계관/캐릭터 정보 저장
- LLM이 설정을 참조하여 초안 생성
- SSE 스트리밍으로 실시간 응답
