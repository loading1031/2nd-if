# AI 스토리 어시스턴트

> 아이디어 메모 (MVP 이후)

## 컨셉
유저가 세계관/등장인물을 입력하면 AI가 스토리 초안을 생성하고, 대화를 통해 디테일을 채워나가는 기능.

## 플로우
1. 유저: 세계관 구조, 등장인물, 설정 입력
2. AI: 스토리 초안 생성
3. 유저 <-> AI: 챗 인터페이스로 디테일 수정/보완
4. 유저: 확정 후 에피소드로 발행

## 기술 방향
- ~~Dify Chatflow 활용~~ → **BYOK 방식으로 전환** ([[ai-byok]] 참조)
- 사용자가 자신의 API 키(OpenAI/Anthropic/Google) 또는 로컬 Ollama를 직접 연결
- 서버는 프록시 역할만, AI 비용은 사용자 부담
- SSE 스트리밍으로 실시간 응답
- 에피소드 작성 페이지의 AI 패널에서 통합 제공

## 향후 확장
- Knowledge Base에 세계관/캐릭터 정보 저장 → 컨텍스트로 활용
- 챗 인터페이스로 디테일 수정/보완 (현재는 단발 생성만)
