# SNS AutoDM 바이럴 루프

> 메모 (MVP 이후)

## 개요
독자가 SNS에 에피소드를 공유하면, 댓글 단 유저에게 AutoDM으로 다음 화 링크를 전송하여 유입시키는 바이럴 루프.

## 플로우
1. 독자가 X/Instagram에 에피소드 요약 카드 공유
2. 다른 유저가 댓글 작성
3. AutoDM으로 "다음 화 읽기" 링크 전송
4. 2nd-if로 유입 → 회원가입 유도

## 에피소드 요약 카드
- 카드뉴스/릴스 형식으로 에피소드 요약 자동 생성
- 작품 표지 + 핵심 문장 + "다음이 궁금하다면?" CTA
- OG 이미지로도 활용 가능

## 필요 API
- X API v2 (DM 전송, 멘션 감지)
- Instagram Graph API (DM, 댓글 웹훅)
