# 세계관 시스템

> 아이디어 메모 (MVP 이후)

## 컨셉
원작 스토리 진행에 따라 세계관 설정(캐릭터 관계, 지도, 아이템 등)이 축적되고,
분기는 원작 세계관을 상속하되 변경분만 관리하는 시스템.

## 구조
- 원작자: 캐릭터/지도/설정 등록 (에피소드 진행에 따라 추가)
- 분기: 원작 세계관 상속 + "이 분기에서 달라진 점"만 override
- 읽기: 원작 세계관 + 해당 분기 변경분이 합쳐져서 표시

## 예시
```
원작 세계관:    A는 죽었다, B는 왕이다
분기 "A 생존":  A는 살았다 (override), 나머지는 원작 그대로
```

## 기술 방향
- Git의 diff처럼 원작 대비 변경분만 저장
- 세계관 항목: 캐릭터, 관계도, 지도, 아이템/보물, 설정
