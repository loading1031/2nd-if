이 페이지는 화면을 검토하는 설계 문서입니다. 이미지·수치는 예시이며 최종 디자인 승인은 아직 받지 않았습니다.

2nd-if 화면 디자인

기준 기획: #26 · 검토 초안 · 2026-10-17

쓰는 법

이 문서는 서비스 화면의 정보 구조와 사용자 이동 흐름을 먼저 정하고, 화면별 설명과 와이어프레임을 검토하기 위한 문서다. 왼쪽 탭에서 화면을 고른다. 제품의 실제 메뉴와 이 문서의 화면 목록은 구분한다.

  • 화면 → 개별 화면과 컴포넌트 → 토큰 순서로 구성한다.
  • 확정된 제품 규칙과 화면 배치 제안을 구분한다. 아직 승인된 디자인 기준은 없다.
  • 컴포넌트와 토큰의 실제 모습은 프로젝트 코드가 기준이다. Tailwind CSS 4.1.18 + daisyUI 5.5.14, light 테마를 사용한다.
  • 와이어프레임은 SVG로 그린 구조 검토용 초안이다. 실제 Tailwind/daisyUI 렌더와 구분한다. 별도 HTML 시안은 동작을 확인하는 보조 자료다.

주요 이동 흐름

1 · 내 작품의 독서 흐름 확인

작품 관리 → 독서 인사이트 → 회차·기간 선택 → 페이지 전환 시간 / 회차 이탈 확인 → 내 작품 유입 또는 공용 합계 → 필요하면 지표 공개 설정

2 · 설정집 채택과 표현 연결

작품의 설정집 목록 → 설정집 탐색 → 상세·버전·라이선스 확인 → 작품에 채택 → 사용할 항목 선택 → 충돌 표현 매핑 → 발행된 작품에서 독자 열람

3 · 새 버전 선택

채택 목록 오른쪽의 “v1.5 업데이트” → 해당 설정집의 버전 검토 → 현재 버전 유지 또는 해당 설정집만 업데이트 → 다른 설정집/다른 작품의 버전은 유지

4 · 설정집 제작자의 발행

내 설정집 → 항목·렌더 이미지 편집 → 흑백 기본형 / 선택 색상 변형 검토 → 라이선스 확인 → 불변 버전 발행 → 채택한 작가가 개별 업데이트 선택

5 · 독자의 시각 에셋 열람

작가가 연결한 본문 표현 → 렌더 이미지 열기 → 닫기 → 같은 읽기 위치로 복귀. 미지정 충돌 표현은 자동 표시하지 않는다.

확정 규칙

  • 작품 열람 권한, 설정집 재사용 라이선스, 지표 열람 권한은 각각 판정한다.
  • 공개 / 링크 공개 작품은 현재 무료로 읽는다. 유료 작품·설정집 결제 구현은 현재 범위 밖이다.
  • 독자는 작품에 포함된 에셋을 별도 설정집 이용권 없이 열람한다.
  • 독자에게 .blend 파일을 제공하지 않는다. WebP/PNG 렌더 이미지를 사용한다.
  • 지표는 작품 품질을 평가하는 점수가 아니다. 분기별 내부 지표는 분기 작가에게 속한다.

열린 결정과 범위 경계

항목현재 처리
작품 고유 공식 설정 색인·팬 설정집#30 별도 도메인. 재사용 설정집과 합치지 않는다.
동적 리더·Blender 자동 생성 파이프라인#15 / #18 보류. 이 문서가 재개 승인을 뜻하지 않는다.
업데이트 시 삭제/변경된 항목과 기존 표현 매핑차이 검토·기존 버전 유지가 가능한 UI를 제안한다. 구체 데이터 이전 규칙은 미정이다.
업로드 크기·해상도, 링크 공개/비공개 이미지 접근구현 전에 확정할 기술·UX 조건이다.
페이지 글자 수, 원작/외전 경로 교체기존 스펙의 미정/제안 상태를 유지한다. 이번 작가 도구 UI 확정과 구분한다.

작품 관리 진입

A-01 · 검토 초안

작가가 작업할 작품을 확인하고 작품별 도구로 진입한다.

진입과 이동

내 작품 → 유리 정원 → 독서 인사이트 / 설정집과 에셋 / 지표 공개 설정

와이어프레임 · 배치 제안

보여 줄 것과 동작

  • 현재 선택한 작품의 이름과 작가를 표시한다.
  • 인사이트, 설정집, 지표 공개 설정의 진입점을 같은 작품 문맥에 둔다.
  • 지표 공개와 작품 공개 상태를 각각 표시한다.

상태와 권한

  • 자기 작품 관리 권한이 없으면 관리 화면을 제공하지 않는다.
  • 다른 작품 선택 시 모든 도구의 작품 문맥을 함께 변경한다.
  • 빈 작품 목록에서는 작품 생성 진입을 보여준다.

확정 규칙

작품 열람·편집 권한과 지표 열람 초대는 분리한다.

열린 결정

메뉴 이름과 순서는 배치 제안이다. 기존 작품 관리 UI와 결합할 위치는 구현 전 검토한다.

독서 인사이트

I-01 · 검토 초안

회차별 읽기 시도와 24시간 이탈 판정, 페이지 전환 시간을 확인한다.

진입과 이동

작품 관리 → 독서 인사이트 → 회차·기간 선택 → 유입 탭 또는 공개 설정

와이어프레임 · 배치 제안

보여 줄 것과 동작

  • 이탈률 분모를 읽기 시작 총량이 아닌 판정 완료 시도로 표시한다.
  • 페이지별 중앙값과 포함 전환 건수를 함께 표시한다.
  • 집계 기준일과 최근 날짜 지연 반영을 안내한다.

상태와 권한

  • 집계 대기, 데이터 없음, 조회 오류, 권한 거부를 구분한다.
  • 계정·기기 간 읽기 시도를 합쳐 독자 수처럼 표시하지 않는다.
  • 마지막 페이지에는 다음 전환 시간이 없다.

확정 규칙

읽기 시작 24시간 후 마지막 페이지 도달 여부로 판정한다. 활성 화면 시간만 포함하고 이탈 시도의 페이지 전환 시간은 제외한다.

열린 결정

기간 선택의 기본값과 페이지 상세 탐색 방식은 UI 제안이다.

근거: author-insights.md · 연결: #28

내 작품 유입·공용 합계

I-02 · 검토 초안

내 작품으로 온 유입과 모든 작가가 공유하는 플랫폼 합계를 구분한다.

진입과 이동

독서 인사이트 → 내 작품 유입 / 공용 컴포넌트 탭

와이어프레임 · 배치 제안

보여 줄 것과 동작

  • 작품 목적지가 자기 작품인 경우에만 상세 유입을 보여준다.
  • 공용 탭은 목적지 작품 이름·ID·개별 성과를 표시하지 않는다.
  • 분기→원작 합류는 원작의 합계로 표시한다.

상태와 권한

  • 공용 탭의 플랫폼 합계와 자기 작품 숫자를 혼동하지 않도록 제목·분모를 구분한다.
  • 분기 작가가 아닌 원작 작가에게 분기 내부 페이지 지표를 보여주지 않는다.
  • 집계가 없으면 0 또는 집계 전 상태를 구분한다.

확정 규칙

클릭률=클릭/노출. 공용 집계에서 목적지별 수치를 분리하지 않는다. 분기 내부 지표는 분기 작가 소유다.

열린 결정

유입 컴포넌트명·배치명 표시 규칙과 분기 합류의 시각 표현은 제안이다.

근거: author-insights.md · 연결: #28

지표 공개·초대

I-03 · 검토 초안

작품의 집계 지표를 볼 계정을 작가가 지정한다.

진입과 이동

작품 관리 → 지표 공개 설정 → 범위 선택 → 필요 시 계정 초대 → 저장

와이어프레임 · 배치 제안

보여 줄 것과 동작

  • 공개 범위는 작가만 / 초대한 계정만 / 전체 공개로 둔다.
  • 초대 계정 목록과 철회 동작을 같은 화면에 둔다.
  • 전체 공개로 바꿀 때 집계 지표의 공개라는 점을 설명한다.

상태와 권한

  • 유효하지 않은 계정, 중복 초대, 자기 계정 초대를 처리한다.
  • 권한이 없는 사용자는 공개 범위나 초대를 편집할 수 없다.
  • 철회 후 다음 대시보드 요청은 현재 권한으로 다시 검사한다.

확정 규칙

작품 열람/편집 권한을 부여하지 않는다. 최소 표본 숨김은 현재 요구사항이 아니다.

열린 결정

계정 검색·초대 수락 UI의 구체 방식은 제안이며 구현 전에 정한다.

근거: author-insights.md · 연결: #28

설정집 탐색

S-01 · 검토 초안

작품에 재사용할 설정집을 찾고 상세·라이선스를 확인한다.

진입과 이동

작품 설정집 목록 → 설정집 추가 → 탐색 → 상세·채택

와이어프레임 · 배치 제안

보여 줄 것과 동작

  • 이름·제작자·버전·이용 조건을 목록에서 확인한다.
  • 설정집 전체의 이용 권한을 확인하고 상세로 이동한다.
  • 유료 배포 가능성은 도메인에 남기되 현재 결제 흐름은 만들지 않는다.

상태와 권한

  • 검색 결과 없음, 로딩, 목록 조회 실패를 구분한다.
  • 이용 권한 없는 설정집은 현재 이용 가능 여부를 분명히 표시한다.

확정 규칙

공용 기본 색상 사전은 기본 리소스로 유지하며 제3자 설정집은 추가 선택이다.

열린 결정

검색 필터, 제작자 프로필 연결, 정렬은 UI 제안이다.

근거: setting-book.md · 연결: #32

설정집 상세·채택

S-02 · 검토 초안

버전과 이용 조건을 확인한 뒤 작품에서 사용할 항목을 선택한다.

진입과 이동

설정집 탐색 → 상세 → 해당 버전 채택 → 사용할 항목 선택 → 작품 설정집 목록

와이어프레임 · 배치 제안

보여 줄 것과 동작

  • 설정집 전체 이용 권한과 작품별 항목 선택을 구분한다.
  • 채택할 버전·라이선스를 확인한 후 작품에 고정한다.
  • 겹치는 용어가 있으면 경고와 표현 매핑 진입을 제공한다.

상태와 권한

  • 권한 만료/없음, 채택 실패, 이미 채택한 버전을 구분한다.
  • 충돌 경고만으로 채택을 일괄 차단하지 않는다.

확정 규칙

설정집 이용 권한은 작가에게 적용한다. 독자는 작품에 포함된 에셋을 별도 이용권 없이 열람한다.

열린 결정

항목 선택을 채택 전/후 어느 단계에서 완료할지는 제안이다.

작품의 설정집 목록

S-03 · 검토 초안

작품이 사용하는 각 설정집의 고정 버전과 업데이트 동작을 확인한다.

진입과 이동

작품 관리 → 설정집과 에셋 → 특정 설정집 버전 검토 또는 표현 매핑

와이어프레임 · 배치 제안

보여 줄 것과 동작

  • 정보는 이름·현재 버전 순서로 배치한다.
  • 작은 업데이트 버튼을 각 행 오른쪽에 정렬한다.
  • 신규 버전은 버튼에 통합하고 “업데이트 가능” 문구를 따로 반복하지 않는다.

상태와 권한

  • 채택 목록 없음이면 설정집 탐색 진입을 제공한다.
  • 한 설정집 업데이트가 다른 설정집이나 다른 작품을 바꾸지 않는다.
  • 유지 선택 후에도 현재 고정 버전이 분명히 보인다.

확정 규칙

모든 설정집을 강제로 함께 업데이트하지 않는다. 채택 버전은 작가의 명시적 선택 전까지 고정이다.

열린 결정

버전 알림의 읽음/미룸 상태 저장 여부는 제안이다.

근거: setting-book.md 및 사용자 수정 지시 · 연결: #32

설정집 버전 검토

S-04 · 검토 초안

변경 내용을 검토한 뒤 해당 설정집만 갱신하거나 현재 버전을 유지한다.

진입과 이동

목록의 v1.5 업데이트 → 검토 모달 → 유지/적용 → 같은 목록으로 복귀

와이어프레임 · 배치 제안

보여 줄 것과 동작

  • 현재·신규 버전과 라이선스를 나란히 비교한다.
  • 연결된 항목이나 이미지의 변경 영향을 먼저 설명한다.
  • 업데이트는 이 작품의 이 설정집에만 적용한다.

상태와 권한

  • 라이선스 변경, 항목 삭제, 매핑 재검토 필요 상태를 구분한다.
  • 실패 시 현재 버전을 유지하며 다시 시도할 수 있다.
  • 취소/유지는 같은 목록과 같은 위치로 복귀한다.

확정 규칙

사용 중인 버전의 라이선스는 변경할 수 없고 새 버전에서만 조건을 변경한다.

열린 결정

삭제된 에셋과 미해결 매핑의 이전/발행 처리 규칙은 아직 확정되지 않았다. 이 와이어프레임은 영향 검토 UI 제안이다.

근거: setting-book.md · 연결: #32

표현·에셋 매핑

S-05 · 검토 초안

동일 표현에 여러 에셋이 연결될 때 작품 문맥에 맞는 하나를 지정한다.

진입과 이동

작품의 설정집 / 에디터 → 충돌 표현 선택 → 후보 비교 → 해당 표현에 연결

와이어프레임 · 배치 제안

보여 줄 것과 동작

  • 출처 설정집·버전·키 종류·색상 값과 이미지 미리보기를 비교한다.
  • 같은 문구라도 해당 작품·표현 문맥별로 연결한다.
  • 원문은 수정하지 않는다.

상태와 권한

  • 후보 없음, 후보 하나, 복수 충돌, 지정한 에셋 접근 실패를 구분한다.
  • 선택하지 않은 충돌 표현에 임의 에셋을 띄우지 않는다.

확정 규칙

작가가 선택하고 독자에게 랜덤 선택 메뉴를 제공하지 않는다. 색상 변형이 없으면 흑백 기본형을 사용한다.

열린 결정

표현 범위의 식별 방식과 편집 후 매핑 유지 방법은 구현 설계에서 정한다.

설정집 항목·에셋 편집

C-01 · 검토 초안

제작자가 재사용 설정 항목과 렌더 이미지·색상 키를 관리한다.

진입과 이동

내 설정집 → 초안 항목 편집 → 이미지/키 검토 → 새 버전 발행

와이어프레임 · 배치 제안

보여 줄 것과 동작

  • 대상 유형을 폐쇄된 고정 목록으로 제한하지 않는 방향을 유지한다.
  • 필요한 키만 채우고 공용 색상 사전과 사용자 별칭을 구분한다.
  • 흑백 기본형을 필수로, 색상 변형을 선택으로 제공한다.

상태와 권한

  • 이미지 누락, MIME/크기 불일치, 업로드 실패, 저장 오류를 표시한다.
  • 제작 권한 없는 계정은 초안을 수정할 수 없다.

확정 규칙

독자 배포는 렌더 WebP/PNG 이미지다. Blender 자동 렌더 farm 및 .blend 원본 배포는 범위 밖이다.

열린 결정

이 화면의 필드 배치와 레이블 세부 모델은 제안이다. 업로드 크기·해상도 규격과 별도 제작자 개발 작업을 구체화해야 한다.

설정집 버전 발행

C-02 · 검토 초안

설정집 제작자가 항목과 이용 조건을 고정한 새 버전을 발행한다.

진입과 이동

설정집 초안 → 발행 전 검토 → 새 버전 발행 → 기존 채택 작품은 업데이트 선택 대기

와이어프레임 · 배치 제안

보여 줄 것과 동작

  • 버전과 라이선스를 함께 검토하고 새 버전으로 발행한다.
  • 이미 채택된 버전의 이용 조건을 덮어쓰지 않는다.
  • 새 버전을 기존 작품에 자동 적용하지 않는다.

상태와 권한

  • 필수 이미지/키 누락, 중복 버전, 업로드 미완료를 표시한다.
  • 발행 권한과 발행 결과를 확인한다.

확정 규칙

조건 변경은 새 버전 또는 새 설정집에서만 가능하다. 작품의 향후 유료화 자격은 채택한 모든 버전의 상업 이용 조건으로 판단한다.

열린 결정

버전 번호 형식, 발행 취소·철회 정책, 라이선스 선택지 목록은 미정이다. 결제 UI는 현재 제외한다.

독서 중 에셋 열람

R-01 · 검토 초안

독자가 본문에서 연결된 렌더 이미지를 보고 읽던 위치로 돌아온다.

진입과 이동

회차 본문 → 연결 표현 탭 → 이미지 오버레이 → 닫기 → 같은 본문 위치

와이어프레임 · 배치 제안

보여 줄 것과 동작

  • 작품 작가가 지정한 연결 에셋을 연다.
  • 닫으면 페이지·읽기 위치를 유지한다.
  • 이미지를 원치 않는 독자는 시각 요소 표시를 끌 수 있는 방향이다.

상태와 권한

  • 이미지 로딩·실패·연결 없음·비공개 접근 거부를 구분한다.
  • 에셋이 열리지 않아도 본문 독서는 계속할 수 있게 한다.

확정 규칙

독자에게 설정집의 별도 구매나 .blend 원본 다운로드를 요구하지 않는다. 원문 읽기 권한으로 필요한 에셋 접근을 판정한다.

열린 결정

모바일 인라인/오버레이 표현과 이미지 확대 UI는 제안이다. 동적 리더 전면 재설계 #15의 재개와 구분한다.
